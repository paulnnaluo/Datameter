# Datameter App Icon Assets

Drop raw Figma exports in `assets/app-icons/figma-export/`.

Preferred source files:

- `datameter-icon.svg` or `datameter-icon.pdf`: editable/vector master.
- `datameter-icon-foreground.svg`: adaptive launcher foreground layer.
- `datameter-icon-background.svg`: adaptive launcher background layer, or a solid color note.
- `datameter-notification.svg`: one-color notification mark.
- `play-store-icon.png`: 512 x 512 px.
- `play-feature-graphic.png`: 1024 x 500 px.

Android production files are generated into `app/src/main/res/`, so keep this folder as the design-source handoff area.
